## Context

ChangePilot 的输入是用户描述的研发变更目标，而可靠工作流内核要求经过验证的结构化任务图。两者之间需要一个规划层：它既要利用大模型处理意图与不完整信息，又不能把模型输出直接当作可执行命令。

用户现有 DeepSeek API 预算有限，且 DeepSeek 不提供本项目所需的托管向量服务。开发与测试必须能够在没有网络和真实 API 调用的情况下重复执行。Runbook 文档属于外部输入，可能过期、互相冲突或包含类似指令的文本，因此必须作为证据数据处理，而不是提升为系统指令。

## Goals / Non-Goals

**Goals:**

- 从自然语言变更目标中识别缺失信息、约束和风险。
- 从本地 Runbook 中检索相关片段，并让规划结论携带可追溯证据。
- 生成满足版本化 Schema 的任务、依赖、工具、风险和验收条件。
- 通过确定性校验阻止无效、无证据或越权计划进入工作流内核。
- 支持 DeepSeek 与 Mock LLM，并记录调用成本和性能数据。

**Non-Goals:**

- 不让 LLM 直接执行有副作用工具。
- 不实现通用互联网搜索、代码生成、多 Agent 群聊或模型训练。
- 不使用 API 进行大规模离线评测。
- 不把检索到的文本视为可信执行指令。

## Decisions

### 1. 使用提供方无关的模型网关

领域层仅依赖结构化对话、工具调用和使用量接口。DeepSeek 通过 OpenAI-compatible 适配器接入，默认模型由环境配置指定，开发配置使用 `deepseek-v4-flash`；测试使用可编排响应和错误的 Mock LLM。

备选方案是直接在业务代码中调用 DeepSeek SDK。该方式更短，但会使测试、模型迁移和成本控制分散，因此不采用。

### 2. 将规划拆成可观察的有限阶段

规划流程分为请求规范化、上下文检查、知识检索、缺失信息判断、计划生成、确定性校验和至多一次格式修复。每个阶段保存输入摘要、输出和耗时，避免无限 Agent 循环。

### 3. 规划输出采用版本化结构化 Schema

计划包含目标、假设、步骤、依赖、工具名、工具参数、风险等级、审批要求、成功条件、补偿意图和证据引用。模型输出先经过 JSON Schema/Pydantic 校验，再经过工具注册、环检测、风险策略和证据完整性检查，最后才能提交工作流内核。

### 4. Runbook 使用本地混合检索并保留来源

文档摄取保存文档 ID、版本、来源、内容摘要和分块位置。V1 采用本地关键词检索与可插拔向量检索的混合接口，不依赖外部向量数据库；每个返回片段都包含稳定引用。具体嵌入模型和本地索引库在深度设计阶段确定。

### 5. 检索内容按不可信数据处理

系统 Prompt、用户目标、工具元数据和检索内容使用独立消息边界。Runbook 中要求泄露密钥、绕过审批或改变系统角色的文本不得生效。计划中的高风险动作仍由确定性策略重新评估，不能由文档声明降级。

### 6. 缺失信息优先澄清，不允许模型猜测关键参数

服务标识、目标版本、迁移标识和验收条件等关键字段缺失时，规划流程返回结构化澄清问题并暂停。用户补充后产生新的计划版本，旧计划不可执行。

### 7. API 预算作为一等运行约束

模型网关记录输入、输出、缓存命中、延迟和估算费用；支持单次规划最大调用数、最大 token 和预算上限。相同请求与相同知识版本可以复用缓存，密钥和完整敏感 Prompt 不进入日志。

## Risks / Trade-offs

- [模型可能生成语法正确但语义错误的计划] → 使用工具白名单、风险策略、证据要求和固定场景评测进行二次约束。
- [本地检索效果低于托管向量服务] → V1 使用小规模高质量 Runbook 和混合检索，并通过检索评测保留替换空间。
- [Mock LLM 无法代表真实模型行为] → 大部分测试验证确定性边界，另保留少量受预算限制的 DeepSeek 集成用例。
- [知识文档过期或冲突] → 保存版本与来源，在冲突时向用户暴露证据并要求确认，不静默选择。
- [Prompt 注入无法仅靠提示词完全防御] → 模型输出始终经过权限和风险策略校验，检索内容不具备直接执行权限。

## Migration Plan

这是新增能力。先实现 Mock LLM 和静态 Runbook 检索形成可重复测试，再接入 DeepSeek 和本地混合索引。模型或索引实现更换时保持网关、检索结果和计划 Schema 不变。

## Resolved Questions

- 使用 LangGraph 编排有限规划流程，领域模型、安全校验和端口保持框架无关。
- 使用 SQLite FTS5/BM25 与可选 `BAAI/bge-small-zh-v1.5` 形成本地混合检索，不要求 Docker 或独立向量数据库。
- 真实 DeepSeek 集成测试默认跳过，仅在显式开关下执行一次受调用数和 token 上限保护的冒烟测试。
