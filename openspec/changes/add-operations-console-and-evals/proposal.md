## Why

一个企业变更 Agent 不能只在终端中输出“执行成功”：操作人员需要在高风险步骤前理解并批准计划，在执行中看到真实状态，在失败后追溯证据；项目也需要固定评测证明安全性和恢复能力，而不是依赖一次精心挑选的演示。

## What Changes

- 提供面向单个操作者的变更运营控制台，用于提交请求、审阅结构化计划、批准或拒绝风险步骤。
- 展示运行状态、步骤依赖、实时事件、工具证据、失败原因、补偿结果和恢复入口。
- 提供不可由前端篡改的审计时间线，并支持导出单次运行的面试演示报告。
- 建立固定离线评测集，覆盖计划有效性、知识引用、安全策略、审批阻断、幂等恢复和补偿回滚。
- 记录延迟、模型调用次数、Token 用量和估算成本，使 DeepSeek 在线评测受明确预算约束。
- 默认评测使用 Mock LLM 与本地沙箱，少量在线样例作为可选验证。

## Capabilities

### New Capabilities

- `operations-console`: 定义变更请求、计划审阅、人工审批、实时执行监控、审计查询和报告导出的用户行为。
- `agent-evaluation`: 定义可复现评测数据集、指标计算、回归阈值、成本统计和结果报告行为。

### Modified Capabilities

无。

## Impact

- 新增本地 Web API、实时事件接口和运营控制台前端。
- 读取可靠工作流、规划 Agent 和执行沙箱的稳定接口，不直接绕过这些模块修改状态。
- 新增评测样例、评测运行器、指标存储和可比较报告。
- V1 面向本地单用户演示，不包含企业级多租户、统一身份认证和复杂 RBAC。
