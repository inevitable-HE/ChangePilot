# ChangePilot 文档

ChangePilot 是一个面向高风险研发变更的受限 AI Agent。它把自然语言变更意图转换为
可审计的任务图，在知识证据、确定性规则和人工审批的共同约束下执行，并在失败或进程
中断后提供补偿、恢复与追踪能力。

## 从哪里开始

- **第一次了解项目**：阅读[中文用户指南](user-guide.zh-CN.md)，用一个订单服务升级
  场景理解完整闭环。
- **准备本地演示**：按照用户指南的“五分钟成功演示”启动 API 和运营控制台。
- **理解 Agent 边界**：阅读[Agent 规划与知识检索](architecture/agent-planning-and-knowledge.md)，
  了解检索、模型规划、规则校验与工作流提交如何协作。
- **理解可靠性设计**：从[架构总览](architecture/index.md)进入工作流、执行沙箱、恢复和
  评测等专题。

## 核心闭环

1. 用户提交服务升级与数据库 Schema 变更意图。
2. Agent 检索版本化 Runbook，为规划建立可追溯证据。
3. 模型生成候选任务图，确定性策略校验依赖、工具权限与风险边界。
4. 高风险步骤进入人工审批，审批结果绑定具体计划版本。
5. 可靠工作流内核执行本地工具，持久化状态、尝试记录和审计事件。
6. 失败时按逆依赖关系补偿；进程中断后根据持久化状态恢复。
7. 运营控制台展示执行证据，评测套件验证规划质量和闭环可靠性。

## 当前边界

当前版本是可运行的工程原型，使用本地沙箱模拟服务发布、Schema 迁移和健康检查，不会
连接真实生产环境。模型只能提出结构化计划，不能绕过工具白名单、确定性校验或人工审批
直接执行高风险操作。
